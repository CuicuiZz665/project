默认跟踪链接 → 合伙人列表顶部 · 3 个方案
目标：把总览页「默认跟踪链接」的能力带到合伙人列表页顶部，让合伙人在这一个页面就能完成「拿链接 → 发链接 → 管比例 → 管人」的完整动线。 三个方案均沿用现有设计语言：渐变描边链接卡、生效中徽章、字段小块、复制交互与总览页完全一致，用户零学习成本。往下滚动对比。
方案 A 独立横条卡 · 页头下方 推荐

在页头与「分佣比例」之间加一条全宽横条链接卡。保留总览页的渐变描边（页面上唯一一张描边卡，视线焦点），但布局从「标题在上、三字段在下」压成一行：左侧标题+徽章，中间三个字段块撑满，右侧二维码/分享。高度约 92px，不挤压下方两区首屏。

✓与总览认知统一，一眼认出 ✓渐变描边 = 页面最高优先级入口 ✓独立模块，将来好扩展（如加数据摘要） ✗页面多一个模块，纵向多占约 92px
